# Project Name
E-Commerce
## Description
- E-Commerce is a RESTful backend application built with Java and Spring Boot to provide core e-commerce functionalities.
- The application allows users to register and log in securely using JWT (JSON Web Token) authentication. It also provides APIs for managing product categories and products.

## Technologies
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven

## Features
### 1. Category Management
- Add Category.
- Get All Categories.

### 2. Product Management
- Add Product.
- Get All Products.

### 3. User Authentication
- User Registration.
- User Login.
- Password Encryption using BCrypt.
- JWT Token Generation.
- JWT Authentication Filter.
- UserDetailsService Integration.
- DaoAuthenticationProvider Configuration.

### 4. API Response Handling
- Standardized API responses using ApiResponse.
